# Decisions

One file per decision that would be expensive to relitigate. Short, dated, and honest about
what would change our mind.

Issues are the wrong home for these — issues close and disappear, and six months from now the
question isn't *what are we building* but *why is this Node*. That answer has to outlive the ticket.

Nothing here is sacred. When one turns out to be wrong, add a note at the bottom saying so and
what replaced it. A reversed decision with its reasoning intact is worth more than a tidy file.

# Prior art

## The agent-pet genre

[clawd-on-desk](https://github.com/rullerzhou-afk/clawd-on-desk) ·
[openpets](https://github.com/alvinunreal/openpets) ·
[codex-pets](https://github.com/codex-pets/codex-pets) ·
[Clyde](https://github.com/QingJ01/Clyde)

It exists — but every one of them is **output-only**. The pet is a status indicator with a face; information
flows agent → pet and never back. None let you click the creature and act.

## The mascot lineage

Neko '89 · eSheep '95 · Shimeji '09 · Desktop Mate

Pure presence with no command layer.

## Adjacent

- [Clippy-with-a-local-LLM](https://github.com/felixrieseberg/clippy) — has input, executes nothing.
- **Command palettes** — input and execution, but no persistence. Summoned by hotkey, then gone.

Gargoyle is the intersection none of them occupy.

> The second creature, which exists to prove the contract is real. It has no limbs, so
> one-arm-per-agent — the octopus's whole mechanic — is unavailable to it. Everything it
> does, it does by being a different shape.

## Voice

Warm and a bit simple. Delighted by ordinary things. Where the octopus is dry, this one is
sincere, which is the point: a creature swap should change the voice as much as the shape.

It would never be sarcastic, and never pretend something is fine when it isn't.

## Moods

| when | it becomes |
|---|---|
| nothing running | round and content |
| a few agents | pleasantly full |
| six or more | stretched rather thin |
| a clean run | thrilled, briefly |
| a failure | droops in the middle |
| after 1am | very slow |
